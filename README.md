## Overview

This repository contains two related projects that demonstrate implementation of foundational market risk models using historical data:

1. A single-asset risk model using SPY (SPY_Risk_Model.ipynb).
2. A multi-asset portfolio risk model using SPY, QQQ, and SMH (MultiAsset_Portfolio_Risk.ipynb).

---

## SPY Risk Model

**Focus:**
- Returns and volatility estimation
- Value-at-Risk (VaR) and Expected Shortfall (ES)
- Gaussian vs historical risk comparison
- Static and rolling VaR backtesting

--- 

## Multi-Asset Portfolio Risk Model

**Portfolio Weights:**
- 40% SPY
- 40% QQQ
- 20% SMH

**Focus:**
- Portfolio construction and returns
- Correlation analysis
- Portfolio VaR and ES
- Portfolio VaR backtesting
